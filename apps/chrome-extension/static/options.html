MCP Connector for web chats

This extension talks only to the MCP Connector app on this computer. In the app, under Web chats, click Create key, then paste the key and the port here.

MCP Connector shows the port next to the key. It is 47820 unless you changed it.

What this extension does

  • It reads the ChatGPT page to find requests written as mcp-call blocks, and puts text in the chat box when you ask.
  • Nothing runs until you click Run in the side panel, and only for tools you ticked for that chat.
  • Whatever needs approval still waits for you in the MCP Connector window.
  • It sends nothing anywhere except to MCP Connector at 127.0.0.1 on this computer.
